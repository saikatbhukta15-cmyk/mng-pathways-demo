# MNG Vision

Create a modern, premium, high-conversion frontend website demo for MNG Academy, Kolkata.

IMPORTANT:
This is a FRONTEND-ONLY project.
There is NO backend, NO database, NO authentication, NO CMS, NO admin panel, NO payment gateway, and NO API requirement.

The goal is to redesign the existing MNG Academy website into a modern training/education website that feels trustworthy, premium, professional, mobile-friendly and much more visually impressive than the current website.

REFERENCE WEBSITE:
https://www.mngacademy.in/

Use the reference website as the content and business reference, but DO NOT copy its old visual design.
The demo should look like a completely modern 2026 training institute website.
